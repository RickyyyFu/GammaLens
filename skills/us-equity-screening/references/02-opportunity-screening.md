# 机会筛选职责与流程

本Skill只在**用户给定范围/行业/主题/股票池或有可验证范围数据**时筛选研究优先级；不能凭网页线索声称“全市场最佳”。通常输出3—8个候选，允许0—2个或为空。

流程：
1. 声明universe来源、总数、取得数、可比数、缺失/排除；未知不打0分。
2. 先以经营质量、主要矛盾、估值要求、盈利/现金变化、催化成熟度建立候选。
3. 再叠加`Positioning / Crowding`作为**路径风险覆盖层**：是否可能被轧空放大，或受到多杀多威胁。
4. 拥挤度不得成为单独买入排名；高SI股票不能因为“容易轧空”压过基本面/估值明显更好的公司。
5. 每个候选输出：核心事实、估值/反向要求、催化、crowding状态、squeeze/unwind触发与失效、数据时点/完整性、交接深研行。
6. 候选不足不凑数；只有新闻线索时降级为lead_discovery。
