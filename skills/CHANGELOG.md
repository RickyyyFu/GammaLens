# Changelog

All notable methodology changes for the equity research skills are recorded here.

## 1.0.0 — 2026-10-02

### Added
- Initial GitHub-maintained release of us-equity-research.
- Initial GitHub-maintained release of cn-a-share-equity-research.
- Shared research philosophy: data integrity, key contradiction, earnings path, valuation, catalysts, execution, risk, falsification, review.
- U.S.-specific handling for GAAP/non-GAAP, fiscal-year estimates, disclosures, buybacks, options and extended-hours execution.
- A-share-specific handling for recurring profit, earnings previews/express reports, estimate-coverage quality, unlock/sell-down/pledge/refinancing risk, T+1/price limits, turnover/free float, PB–ROE, and policy transmission.

### Maintenance policy
- Use semantic versioning.
- Behavior changes require a CHANGELOG entry.
- Screening thresholds and backtest assumptions must not be silently optimized after outcomes are known.
