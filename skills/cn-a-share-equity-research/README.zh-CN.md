# A股选股与投资研究 Skill

[English](./README.md) | 简体中文

这是在同一套核心研究框架上，为沪深北A股做本土化后的自包含Skill。

## A股版额外强制检查

- 归母净利润 vs 扣非归母净利润
- 业绩预告 → 业绩快报 → 正式财报
- 一致预期覆盖机构数、更新时间和预测分歧
- 解禁、减持、股权质押、定增、可转债、再融资
- T+1、涨跌停、停牌、ST/风险警示与止损无法成交
- 换手率、自由流通盘、股东结构
- 金融和成熟央国企适用的PB–ROE等估值
- 政策 → 订单 → 收入 → 利润 → 现金流

## 常见用法

> 全市场筛选A股未来12–24个月值得研究的标的。必须检查扣非利润、业绩预告/快报、一致预期覆盖、解禁减持、换手/自由流通结构、估值和政策到利润的传导。

## 边界

A股交易制度可能调整。真实执行前必须核对当前交易所关于涨跌幅、申报数量、T+1、ST、停牌等规则。本Skill只做研究，不连接券商、不自动下单、不保证收益。
