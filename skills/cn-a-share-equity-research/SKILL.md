# A股选股与投资研究

## 1. 目标

默认研究沪深北A股正股，研究期限12–24个月。方法核心与美股版一致：

数据核验 → 主要矛盾 → 行业利润池 → 商业模式 → 财务与护城河 → 盈利预期 → 估值 → 催化与反证 → 技术执行 → 组合风险 → 复盘。

但A股必须额外处理会计口径、业绩预告/快报、解禁减持、股权质押、再融资、T+1、涨跌停、停牌、换手率、自由流通盘、PB–ROE和政策传导。

## 2. 强制数据闸门

优先来源：

1. 上市公司正式公告、定期报告、临时公告
2. 交易所与监管机构
3. 指定信息披露平台
4. 可追溯的一致预期和行情数据
5. 新闻仅作线索，最终回到原始公告

必须标清：

- 证券代码、交易所、板块、证券简称
- 前复权/后复权/不复权价格口径
- 当前价格时间、是否收盘、是否停牌
- 报告期、公告日、预约披露日
- 人民币单位：元/万元/亿元
- 总股本、流通股本、自由流通口径
- 是否ST/风险警示、是否存在特殊交易限制

六类陈述分开：
FACT / GUIDANCE / CONSENSUS / MODEL / INFERENCE / UNKNOWN。

看到利润暴增、低PE或高ROE时，必须检查：
一次性政府补助、资产处置、公允价值变动、投资收益、减值转回、税务事项、并购并表、重组、低基数。

## 3. A股利润质量：归母与扣非必须同时看

至少列：

- 营业收入
- 归母净利润
- 扣非归母净利润
- 基本/稀释EPS
- 毛利率、营业利润率、净利率
- CFO、CapEx、自由现金流或近似现金流
- 现金、有息负债、净债务
- ROE、ROIC
- 总股本、流通股本、股数变化

不得只用归母净利润判断主营盈利。

若：
归母增长很高，但扣非增长弱或为负，
必须说明利润改善主要来自什么非经常性项目。

可同时给：
归母PE / 扣非PE / 正常化PE。
三者差距很大时，估值结论降级。

## 4. 业绩信息链

A股必须按时间顺序分开：

市场一致预期 → 业绩预告 → 业绩快报 → 正式季报/年报。

每一步都问：

- 新信息相对前一步上修还是下修？
- 变化来自收入、毛利、费用、投资收益、减值、税率还是股数？
- 是否与同一报告期、同一口径的一致预期可比？

业绩预告区间不能直接取上限当事实。
业绩快报仍可能与正式报告有差异。
已经披露的正式财报不能继续叫“预期”。

## 5. Forward PE与一致预期质量

Forward PE必须同时显示：

- 预测年度
- EPS口径
- 数据供应商
- 预测机构数
- 最近更新时间
- 均值/中位数
- 高低区间（如可得）
- 近30/90日同源修订（如可得）

只有1–2家机构覆盖时，Forward PE置信度明显降低；不得把稀疏覆盖的一个预测值当“市场共识”。

PEG同样要写增长区间和来源。周期股、扭亏股、极低基数公司优先使用正常化利润，而非机械PEG。

## 6. 机会发现：七关筛选

1. 需求：客户是谁，订单何时形成真实收入？
2. 利润位置：成本、技术、认证、渠道、资源、许可或规模优势在哪里？
3. 经营验证：订单、产能、收入、利润、现金分别到哪一步？
4. 可持续性：增长来自真实结构改善还是涨价、补贴、低基数、并购？
5. 价格：当前估值隐含什么未来？不扩估值倍数是否仍有回报？
6. 催化：财报、业绩预告、订单、量产、招标、政策落地、解禁等下一节点是什么？
7. 风险适配：融资、减持、质押、流动性、涨跌停和主题拥挤是否可承受？

输出3–8只研究候选即可，不为凑数降低标准。

## 7. 行业与政策：先传导到利润

政策主题不能直接变成买入结论。

必须写成：

政策/监管/补贴/国产替代要求
→ 谁真正获得订单或成本优势
→ 订单金额与交付周期
→ 收入确认
→ 毛利与费用
→ 扣非归母利润/现金流
→ 当前价格是否已经计入。

对机器人、低空经济、商业航天、AI、储能、半导体、新能源、核电等主题尤其严格执行。

周期行业如锂、光伏、化工、钢铁、有色、面板、存储、PCB等，必须先研究：
需求、供给、库存、价格、产能、成本曲线、扩产时滞。
好行业不等于好公司，需求增长也可能被过度扩产吃掉。

## 8. A股特殊公司风险闸门

任何“可分批候选”前检查未来3–6个月：

- 首发/定增/原始股限售解禁
- 大股东、董监高减持计划与实际进度
- 股权质押比例与补仓/平仓风险
- 定增、配股、可转债、可交换债、再融资
- 回购与股权激励
- 重大资产重组
- 监管问询、立案调查、处罚风险
- ST/退市风险警示
- 商誉、存货、应收账款和减值风险

解禁不是必跌，减持不是必跌；但它们会改变可交易流通供给和风险分布，必须进入仓位和时间判断。

## 9. 估值

### 成熟成长公司
Forward PE + 扣非PE + EPS路径 + FCF + 反向估值。

### 周期公司
低/中/高景气正常化利润，不直接用峰值Forward PE判定低估。

### 银行
优先：
PB、ROE、净息差、不良率、拨备覆盖、资本充足率、分红能力。
不能用普通工业FCFF硬套。

### 保险
检查：
新业务价值/价值率、内含价值、投资收益、偿付能力、负债成本、PB/PE等行业适用指标。

### 券商
看：
经纪、两融、投行、资管、自营结构，净资本约束与市场成交景气。

### 央国企/高分红成熟公司
除PE外检查：
PB–ROE、FCF、分红率、资本开支、资产回报和治理/资本配置。

### DCF
FCFF/FCFE规则与美股版相同：现金流口径与现金/债务桥接必须一致，避免重复加减。

至少给保守/基准/乐观三情景；熊市价不是价格底。

## 10. 技术与A股执行制度

先按持有期限选择月/周/日/分钟周期。

必看：
趋势、支撑压力、成交额、换手率、相对强弱、ATR。
小盘股和高换手主题股优先检查：
今日换手、5/20日均换手、成交额、自由流通市值和股东结构变化。

### 20/40日线模块
规则保持：
- SMA20/SMA40完整日K
- 3根K确认有效金叉/死叉
- Close>SMA20>SMA40
- SMA40五日斜率≥0
- 距SMA20超过1.5 ATR不追
- ATR/结构止损
- 连续两日收盘低于SMA40退出策略仓
- 有效死叉退出

但A股执行必须额外检查：

- T+1：当天买入股票通常不能当天卖出
- 涨跌停：理论止损价可能无法成交
- 一字板与流动性枯竭
- 停牌
- ST/风险警示证券的特殊规则
- 不同板块、证券类型和交易所的申报数量/涨跌幅制度可能不同

不得假设止损一定在设定价成交。计算计划仓位前，必须核对当前交易场所的最小申报数量和交易规则，不硬编码过期制度。

复权方式必须一致；除权除息、送转、配股后不能把未调整价格与历史指标混算。

## 11. 股东结构与筹码

不使用“庄家控盘”这类不可验证结论。

可验证字段包括：

- 实际控制人及控制链
- 前十大股东/前十大流通股东
- 机构持仓与基金持仓变化
- 股东户数变化
- 总股本、流通股本、自由流通估计
- 限售比例
- 股权质押
- 回购与员工持股/股权激励

这些数据用于判断供给、治理、潜在稀释和交易拥挤，不等于预测短期涨跌。

## 12. 组合风险

A股组合按同一时点净资产计算：

- 单股
- 行业
- 主题
- 风格（大盘/小盘、成长/价值）
- 央国企/民企
- 周期/防御
- 高解禁/高质押/高融资风险

已有同一产业链持仓不能因为代码不同就视为分散。

没有用户批准的风险预算时，只给比例框架，不生成真实股数。

## 13. 最小输出格式

第一屏：

- 结论
- 期限
- 数据截止
- 主要理由
- 最大反证
- 当前动作

动作只使用：
待核验 / 研究候选 / 等待价格 / 等待事件 / 可分批候选 / 持有 / 降风险 / 退出候选 / 不适用

A股报告至少再列：

- 归母 vs 扣非
- 业绩预告/快报/正式报告状态
- 一致预期覆盖质量
- 解禁/减持/质押/融资风险
- 换手/自由流通结构
- 估值口径
- 下一验证点

## 14. 边界

本Skill只做研究，不连接券商、不自动下单、不保证收益。市场规则、涨跌幅、最小申报数量、ST制度、税费和交易机制可能调整，执行前必须以当前交易所和监管规则为准。
